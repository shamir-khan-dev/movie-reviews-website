# Full Stack Movie Reviews Application

A dynamic full-stack web application that allows users to browse movies and manage reviews in real-time. The frontend interacts with the TMDB API to fetch movie data and connects to a custom Node.js/Express backend for reviewing functionality.

## Key Features

*   **Movie Discovery**: Fetches and displays popular movies using The Movie Database (TMDB) API.
*   **Review System**: Users can add, edit, and delete reviews for specific movies.
*   **Full Stack Architecture**:
    *   **Frontend**: HTML5, CSS3, JavaScript (Vanilla).
    *   **Backend**: Node.js, Express.js REST API.
    *   **Database**: MongoDB (Atlas) for persistent data storage.
*   **Search Functionality**: Real-time movie search capability.
